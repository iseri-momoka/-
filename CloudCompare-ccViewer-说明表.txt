CloudCompare ccViewer/ 目录下全部文件说明表
================================================================================

ccViewer 是 CloudCompare 的轻量级 3D 查看器（CloudCompare Light Viewer），
是一个独立的可执行程序，仅提供文件加载+3D浏览功能，无编辑/处理能力。


一、源文件（7 个）
────────────────────────────────────────────────────────────────────────────────
| 序号 | 文件名                   | 类型     | 作用                                                              |
|------|--------------------------|----------|-------------------------------------------------------------------|
| 1    | main.cpp                 | 入口点   | 程序入口，初始化 OpenGL/Qt、加载 I/O 插件、处理命令行参数(-WIN/-MAX)|
|      |                          |          | 创建 ccViewerWindow 并加载拖入/命令行传入的文件                      |

================================================================================
架构关系
================================================================================

  ccViewer.exe
  ├── CCAppCommon (ccApplicationBase, ccPluginManager, 翻译, 设置对话框)
  ├── CCPluginStub (插件接口: ccGLPluginInterface, ccIOPluginInterface)
  ├── qCC_db (ccHObject, ccPointCloud, ccGenericMesh 等实体)
  ├── qCC_glWindow (ccGLWindowInterface - OpenGL 3D 渲染)
  ├── qCC_io (FileIOFilter - 文件读写, 内置过滤器)
  ├── CCPluginAPI (ccMainAppInterface - 主程序接口)
  └── Qt6 (Widgets, OpenGLWidgets, Concurrent)

  与主程序 qCC 的区别:
  ┌─────────────┬──────────────────────┬──────────────────────┐
  │ 能力         │ qCC (主程序)          │ ccViewer (轻量查看器)  │
  ├─────────────┼──────────────────────┼──────────────────────┤
  │ 文件加载     │ 全格式(I/O插件+内置)  │ 全格式(I/O插件+内置)  │
  │ 3D 浏览      │ 多窗口 MDI           │ 单窗口                │
  │ 实体编辑     │ 全部支持              │ 不支持                │
  │ DB 树        │ 完整树视图            │ 无树视图              │
  │ 插件类型     │ Standard + GL + IO   │ GL + IO 仅           │
  │ 命令行模式   │ 支持                 │ 不支持(仅查看)        │
  │ 标量场操作   │ 全部                  │ 仅浏览                │
  │ 点云处理     │ 全部                  │ 不支持                │
  │ 网格编辑     │ 全部                  │ 不支持                │
  └─────────────┴──────────────────────┴──────────────────────┘
